# 1CloudAI CRM AI Studio skills

A reusable AI-agent skill for working with 1CloudAI CRM AI Studio through direct code editing or the builder's prompt interface.

## Install

Copy `skills/1cloudaicrm-ai-studio` into your agent's skills directory (for Codex, `~/.codex/skills/`). Restart or refresh the agent if necessary. Invoke `$1cloudaicrm-ai-studio` when working on a project, or allow your agent to select it automatically.

The skill describes a workflow; access to an authorized 1CloudAI CRM session and a compatible browser or computer-use tool is still required. It contains no project source code or credentials.
